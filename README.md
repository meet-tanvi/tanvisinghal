# Tanvi Singhal portfolio prototype

A redesign of https://meet-tanvi.github.io/tanvisinghal/ as a multi-page site. There is nothing to install.

## View it

Double-click `index.html`. It opens in your browser. Fonts load from Google Fonts when you are online, and the site falls back to Georgia and Segoe UI when you are offline.

## Pages

| Page | File |
| --- | --- |
| Home (introduction, about, expertise, education) | `index.html` |
| Work overview | `work.html` |
| Corporate and strategic communications | `work-corporate.html` |
| Foundation, CSR and community impact | `work-impact.html` |
| Executive communications and thought leadership | `work-executive.html` |
| Internal and employee communications | `work-internal.html` |
| Marketing, brand and campaigns | `work-marketing.html` |
| Social media and digital | `work-digital.html` |
| Case studies overview | `case-studies.html` |
| TIFF: The Market | `case-tiff.html` |
| LinkedIn content program | `case-linkedin.html` |
| Household electrification | `case-electrification.html` |
| *Watts Up* | `case-watts-up.html` |
| REC 50th anniversary book | `case-rec-50.html` |
| Experience | `experience.html` |
| Recognition | `recognition.html` |
| Contact | `contact.html` |

Each `work-*.html` and `case-*.html` page has its own web address, so a resume can link straight to the most relevant samples.

The site opens in light mode. The switch in the header changes it to dark mode, and the browser remembers that choice.

## Editing

- Text lives in the HTML file for each page.
- Colours and spacing live at the top of `css/site.css`.
- The document reader's list of publications is in `js/site.js`.
- The header and footer are repeated in every page, so a change to the menu has to be made in all 17 files.
